# dentalanto

Digitalizador inteligente de cuadernos odontológicos a Excel y PDF con IA Multimodal (Google Gemini).

## Características
- Captura de fotos en vivo desde móvil/webcam o subida de imágenes/escaneos.
- Reconocimiento de manuscritos en cuadernos contables y clínicos dentales.
- Extracción estructurada de:
  - Atenciones y Pacientes (Fecha, Boleta, Doctora, Paciente, Tratamiento, Efectivo, Banco, Comisión y Observaciones).
  - Gastos Diarios con Observaciones.
  - Cuadre y Resumen Financiero de Caja.
- Exportación directa a Excel (.xlsx) y PDF.

## Instalación y Ejecución
```bash
pnpm install
pnpm dev
```
